# UE\_ContainerRappingTest

Unreal Project for Container Wrapping Test \& Pointer



### NBC\_Unreal08\_차지훈

TArray, TSet, TMap 등 Unreal에서 지원하는 컨테이너 테스트

Enter Key 입력 : Test 캐릭터에게 아이템 추가
Left Mouse Button 입력 : 바라보는 아이템 사용 시도
Right Mouse Button 입력 : 바라보는 아이템을 사용하기 위한 칭호 획득
